Set up before the meeting

Open a terminal in the repo and run npm install once. Have npm run turn ready to type. The demo needs no API key, no database and no internet — it runs entirely on a laptop, which is itself worth mentioning.

Part IThe one-minute version

Say this

“A guest in a hotel room says something out loud. We turn that into an action — adjusting their lights or temperature, raising a maintenance ticket, ordering food — and we say something back.

The old system matched what the guest said against a fixed list of phrases. If the phrase wasn't on the list, it failed. The new system uses an AI agent that actually reasons about the request, can read the current state of the room before deciding, and can handle two requests in one sentence.

The important part is not the AI. It's that the AI is not allowed to do anything on its own. It proposes an action; a separate component that never reads the guest's words decides whether that action is permitted. That's what makes it safe to put in forty thousand bedrooms.”

The three sentences that matter most

1
It understands, instead of matching. “It's freezing in here and can you fix the shower” is two requests, one of which needs a free-text description. The old system fails on that sentence. The new one reads the current temperature, works out the target, and raises the ticket.
2
A new hotel is configuration, not code. Every hotel uses a different room-automation vendor. We built an abstraction so the agent knows about “a thermostat with a temperature range” and never about Honeywell or Interel. Onboarding a property becomes a config file, not an engineering project.
3
The AI proposes; the platform decides. Every single action passes through a policy component that checks which room you're in, whether the action is permitted there, whether it costs money, and whether it needs the guest to confirm out loud. That component never reads the guest's words — so no matter what someone says to the device, they cannot talk it into doing something it isn't allowed to do.
If your manager asks only one question, it will be this

“What stops the AI doing something stupid or expensive?”

Answer: the AI has no ability to act. It can only suggest. A separate, small, independently tested component authorises every action, and it decides using structured data — which room, which tool, what it costs — not the guest's sentence. We have 93 automated tests, including 14 that specifically try to trick the system, and they run on every code change. A failure blocks the release.
