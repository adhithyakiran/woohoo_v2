This guide covers two jobs that meet in the middle: getting hotel data into the system, and getting commands out to the room. Before either, three honest statements about the current build.

The one idea that governs everything in this guide

The agent reasons about capabilities, never about vendors. It knows there is "a thermostat in the bedroom zone with a permitted range". It has never heard of INNCOM, Interel, BACnet objects or KNX group addresses.

Every vendor-specific fact lives in exactly two places: an adapter, and a per-property capability manifest. If vendor vocabulary ever appears above those, the abstraction is broken and adding the next hotel becomes an engineering project again.
