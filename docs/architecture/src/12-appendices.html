 MODULE BOUNDARY RULES (lint-enforced — this is what makes the monolith modular rather than a ball of mud)
 1. A module may only be reached through its public interface. No cross-module imports of internals.
 2. A module may only touch its own tables. Cross-module data access goes through the interface.
 3. No module imports from `adapters/` — vendor concepts never travel upward.
 4. `agent/` may not import `policy-service` types except the verdict contract. It must not be able
    to evaluate policy itself.
 5. `contracts/` imports nothing. Everything else may import it.

Appendix EGlossary

TermMeaning in this document
Agentic laneThe routing path where Gemini reasons over the tool surface. Contrast: fast lane, clarify lane.
CapabilityAn abstract, vendor-neutral ability (e.g. climate.setpoint) with a typed contract. The unit of abstraction that keeps vendor differences out of the model.
Capability manifestPer-room-type declaration of which capabilities exist, with zones, bounds and driver bindings. Generates the tool surface.
CellA complete, independent regional stack. No guest data crosses a cell boundary.
ContainmentThe proportion of turns resolved without staff involvement.
Edge GatewayThe on-premise appliance that terminates vendor protocols, holds local state and provides offline fallback.
Fast laneDeterministic handling of high-frequency utterances with no LLM call.
Filled pauseA cached acknowledgement played while the agent works, so perceived latency is far below actual latency.
MCPModel Context Protocol — the standard by which capabilities are exposed to a model.
MCP GatewayThe internal control point through which all tool calls pass. Injects scope, filters tools, sanitises results, audits.
PDPPolicy Decision Point — the component that authorises or refuses every proposed tool call. Sits outside the model.
Phrase packPre-synthesised common phrases cached on the device per voice and language.
Risk tier (T0–T5)The classification that determines what the platform requires before an action executes. Defined in §44.
ScopeThe immutable {tenant, property, room, device} tuple derived from the device certificate and injected into every tool call.
Shadow evaluationReplaying fast-lane turns through the agentic lane offline to detect divergence.
TurnOne complete wake-to-response interaction. The unit of tracing, auditing, billing and evaluation.
TurnContextThe immutable per-turn record of scope, capability version, language, consent state and time that follows a turn through every component.
